# 🤖 Guia do Motor de IA e Prompt Engineering — OpenRouter API

Este guia detalha o funcionamento técnico do **Motor de IA**, integração via HTTP fetch, proteção contra vazamento de chaves (Secret Scanning) e engenharia de prompts estruturados para bancas examinadoras.

---

## 🔑 1. Proteção de Chaves API (GitHub Secret Scanning)

### ⚠️ O Problema:
Se uma chave da OpenRouter ou OpenAI for deixada hardcoded em arquivos HTML (`value="sk-or-v1-..."`), os robôs do GitHub detectam o token e **bloqueiam o push com erro HTTP 422**.

### 🛡️ A Solução Aplicada:
1. O código HTML contém um valor vazio por padrão (`value=""`).
2. A chave API é informada através de uma janela modal discreta (`🔑 Configurar Chave API`).
3. A chave é salva com segurança no `localStorage` do navegador do usuário (`openrouter_api_key`).

```javascript
document.getElementById("btn-config-key").addEventListener("click", () => {
  const currentKey = localStorage.getItem("openrouter_api_key") || savedSettings.apiKey || "";
  const newKey = prompt("Informe sua chave API OpenRouter (salva com segurança no navegador):", currentKey);
  if (newKey !== null) {
    savedSettings.apiKey = newKey.trim();
    localStorage.setItem("openrouter_api_key", newKey.trim());
    saveCurrentSettings();
    if (newKey.trim()) alert("Chave API salva com sucesso!");
  }
});
```

## 🎛️ 2. Seleção de Modelos & Níveis de Pensamento (Thinking Level)

O painel de configuração permite alternar dinamicamente entre os melhores modelos de IA em tempo real:

- **Modelos Suportados**:
  - `google/gemma-4-31b-it` (Google Gemma 4 31B - Excelente raciocínio e custo benefício)
  - `deepseek/deepseek-v4-flash-0731` (DeepSeek V4 Flash 0731 - Alta velocidade e profundidade técnica)
- **Níveis de Pensamento (Thinking Level)**:
  - `Low`: Respostas diretas, enunciados concisos.
  - `Medium`: Análise equilibrada.
  - `High`: Raciocínio analítico profundo, rigor conceitual máximo e explicações minuciosas.
- **Níveis de Dificuldade**:
  - `Fácil`: Conceitos fundamentais.
  - `Médio`: Aplicação prática e cenários reais.
  - `Difícil`: Casadinhas conceituais complexas, pegadinhas da banca e cenários de alta complexidade.

## 📝 3. Prompt Engineering & Estrutura JSON Estrita

O prompt enviado para a OpenRouter API é dinâmico e injeta todas as configurações selecionadas:

```javascript
async function generateQuestionsWithAI(banca, topics, count, model, apiKey, difficulty = "Médio", thinkingLevel = "High") {
  const topicObjList = TOPICS_CATALOG.filter(t => topics.includes(t.id));
  const topicLabels = topicObjList.map(t => t.label).join("; ");
  
  const formatDesc = banca === "CEBRASPE" 
    ? "Formato CEBRASPE: Certo ou Errado. Cada questão DEVE ter exatamente 2 opções: A) Certo, B) Errado."
    : `Formato ${banca}: Múltipla Escolha. Cada questão DEVE ter 5 opções marcadas como A, B, C, D, E.`;

  const prompt = `Você é um especialista e examinador sênior da banca ${banca} para o concurso Petrobras.

CONFIGURAÇÕES ESTRITAS DA PROVA:
- Nível de Raciocínio / Thinking: ${thinkingLevel.toUpperCase()} (Low = respostas diretas e concisas; Medium = análise equilibrada; High = raciocínio analítico profundo, rigor conceitual máximo e justificativas minuciosas).
- Nível de Dificuldade da Questão: ${difficulty.toUpperCase()} (Fácil = conceitos fundamentais; Médio = aplicação prática e cenários reais; Difícil = casadinhas conceituais complexas, pegadinhas da banca e cenários críticos).
- Assuntos Selecionados: Elabore as questões EXCLUSIVAMENTE focadas nos seguintes assuntos específicos: [${topicLabels}].

Regras de Formato:
1. ${formatDesc}
2. O enunciado deve ser técnico, bem contextualizado e sem ambiguidade.
3. Forneça uma explicação técnica minuciosa justificando o gabarito.
4. Retorne EXCLUSIVAMENTE um objeto JSON válido sem Markdown fora do JSON, no seguinte esquema:
{
  "items": [
    {
      "id": "ai-q-1",
      "topicId": "${topics[0] || ''}",
      "statement": "Texto do enunciado da questão...",
      "options": [
        { "label": "A", "text": "Texto da opção A" },
        { "label": "B", "text": "Texto da opção B" }
      ],
      "correctLabel": "A",
      "explanation": "Explicação técnica detalhada..."
    }
  ]
}`;

  const response = await fetch("https://openrouter.ai/api/v1/chat/completions", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${apiKey}`,
      "Content-Type": "application/json",
      "HTTP-Referer": "https://concurso-petrobras-study.local",
      "X-Title": "Concurso Petrobras RAG"
    },
    body: JSON.stringify({
      model: model,
      messages: [
        { role: "system", content: `Você é um examinador especialista de alto nível. Nível de pensamento: ${thinkingLevel.toUpperCase()}.` },
        { role: "user", content: prompt }
      ],
      response_format: { type: "json_object" }
    })
  });

  const data = await response.json();
  const content = data.choices?.[0]?.message?.content;
  const cleanJson = content.replace(/^```json\s*/i, "").replace(/```\s*$/i, "").trim();
  const parsed = JSON.parse(cleanJson);
  return parsed.items;
}
```

## 🔄 4. Fallback Automático para o Banco Offline

Se a API do OpenRouter falhar (falta de crédito, cota excedida ou instabilidade na rede), a aplicação faz um **fallback transparente para o banco de dados offline**, garantindo que o usuário nunca fique impedido de estudar.
