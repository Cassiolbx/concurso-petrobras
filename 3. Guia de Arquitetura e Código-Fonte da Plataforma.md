# 🏗️ Guia de Arquitetura e Código-Fonte — Plataforma de Estudos Interativa

Este guia fornece o passo a passo completo para recriar a arquitetura técnica da plataforma de estudos em qualquer novo projeto ou concurso.

---

## 🎯 1. Filosofia de Arquitetura (Vanilla JS Single-File)

A plataforma utiliza a estratégia **Single-File Application (SFA)** com JavaScript puro (Vanilla JS), HTML5 semântico e CSS3 puro.

### 🌟 Vantagens desta Escolha:
- **Zero Dependências**: Não exige Node.js, `npm`, webpack, Vite ou frameworks pesados.
- **Funcionamento Offline Nativo**: Pode ser aberto direto pelo navegador a partir de uma pasta local, celular ou pendrive.
- **Carregamento Instantâneo**: Desempenho máximo com 100% dos estilos e scripts carregados em uma única requisição.

### 🔄 Controle em JavaScript
```javascript
const THEME_KEY = "flashcards:materia:theme";
let currentTheme = localStorage.getItem(THEME_KEY) || "dark";

function applyTheme(theme) {
  currentTheme = theme;
  document.documentElement.setAttribute("data-theme", theme);
  localStorage.setItem(THEME_KEY, theme);

  const icon = document.getElementById("theme-icon");
  const label = document.getElementById("theme-label");

  if (theme === "light") {
    icon.textContent = "☀️";
    label.textContent = "Claro";
  } else {
    icon.textContent = "🌙";
    label.textContent = "Escuro";
  }
}

document.getElementById("theme-toggle-btn").addEventListener("click", () => {
  applyTheme(currentTheme === "dark" ? "light" : "dark");
});

applyTheme(currentTheme);
```

## 🖥️ 3. Estrutura das 3 Telas (Views)

A aplicação transita suavemente entre três painéis principais no mesmo arquivo HTML:

1. **`view-setup` (Configuração)**:
   - Escolha do Motor (Offline vs IA OpenRouter).
   - Filtro por Assuntos/Tópicos específicos do edital.
   - Seleção da Banca (CESGRANRIO, CEBRASPE, FGV, FCC).
   - Quantidade de questões (5, 10, 15, 20).
   - Botões de ação (▶ Iniciar Treino, 🔄 Revisar Erros, ☁️ Backup Google Drive).

2. **`view-exercise` (Área de Treino)**:
   - Barra de progresso dinâmica (`0%` a `100%`).
   - Timer em tempo real (`⏱️ 00:00`).
   - Badges com Banca, Tópico e Motor em execução.
   - Cartões de opções com hover e efeito de seleção neon.
   - Banner de feedback instantâneo com gabarito oficial e explicação comentada.

3. **`view-results` (Resumo Final)**:
   - Grade de métricas (Acertos, Acurácia %, Tempo Total, Banca/Motor).
   - Lista com o detalhamento questão por questão (Correta ✅ / Errada ❌).

## ⌨️ 4. Atalhos de Teclado (Produtividade)

Permite responder e navegar rapidamente sem usar o mouse:

```javascript
document.addEventListener("keydown", (e) => {
  if (views.exercise.classList.contains("hidden")) return;

  const q = currentSession.questions[currentSession.currentIndex];
  const resp = currentSession.responses[q.id];

  if (!resp) {
    const key = e.key.toUpperCase();
    let targetLabel = null;

    if (['1', '2', '3', '4', '5'].includes(key)) {
      const idx = parseInt(key, 10) - 1;
      if (q.options[idx]) targetLabel = q.options[idx].label;
    } else if (['A', 'B', 'C', 'D', 'E'].includes(key)) {
      if (q.options.some(o => o.label === key)) targetLabel = key;
    }

    if (targetLabel) {
      const item = document.querySelector(`.option-card[data-label="${targetLabel}"]`);
      if (item) item.click();
    }

    if (e.key === "Enter" && !document.getElementById("btn-confirm-answer").disabled) {
      confirmAnswer();
    }
  } else {
    if (e.key === "Enter" || e.key === "ArrowRight") {
      document.getElementById("btn-next-question").click();
    }
  }
});
```

## 📋 5. Caderno de Erros (Revisão Inteligente)

Toda questão respondida incorretamente é armazenada no `localStorage`:

```javascript
if (!isCorrect) {
  if (!wrongQuestions.some(wq => wq.id === q.id)) {
    wrongQuestions.push({
      ...q,
      failedAt: new Date().toISOString()
    });
    saveStorage(KEYS.WRONG, wrongQuestions);
  }
} else {
  if (currentSession.mode === "review") {
    // Ao acertar na revisão, remove a questão do caderno de erros
    wrongQuestions = wrongQuestions.filter(wq => wq.id !== q.id);
    saveStorage(KEYS.WRONG, wrongQuestions);
  }
}
```
