# 📄 Guia de Extração de Assuntos e Questões a partir de PDFs

Este guia ensina como extrair os tópicos do edital e questões de provas anteriores contidas em arquivos **PDF**, convertê-los para o formato JavaScript da aplicação e alimentá-los no **Motor de IA**.

---

## 📑 1. Estruturação dos Tópicos do Edital no Código

Ao abrir o PDF do edital do concurso, localize a seção de **Conteúdo Programático** e estruture os tópicos no catálogo da matéria (`TOPICS_CATALOG`).

### 💡 Formato no Código JavaScript:
Em cada arquivo `.html` da matéria, edite a constante `TOPICS_CATALOG`:

```javascript
const TOPICS_CATALOG = [
  { 
    id: "modelagem-er-normalizacao", 
    label: "Modelagem ER, Relacional & Normalização (1FN a 5FN)" 
  },
  { 
    id: "linguagem-sql-avancada", 
    label: "Linguagem SQL (DDL, DML, DCL, Window Functions, CTEs & Subqueries)" 
  },
  { 
    id: "transacoes-acid-concorrencia", 
    label: "Transações, Propriedades ACID, Isolamento & Controle de Concorrência" 
  }
];
```

## 📦 2. Extração de Questões de PDFs de Provas Anteriores

Se você possui PDFs com provas e gabaritos comentados das bancas (CEBRASPE, CESGRANRIO, FGV, FCC), você pode inseri-las no banco offline (`QUESTION_BANK`) para treino sem internet.

### 💡 Formato do Banco Offline (`QUESTION_BANK`):

#### 🔹 Para Bancas de Múltipla Escolha (CESGRANRIO, FGV, FCC):
```javascript
const QUESTION_BANK = {
  CESGRANRIO: [
    {
      id: "bd-ces-01",
      topicId: "modelagem-er-normalizacao",
      statement: "Enunciado completo copiado do PDF da prova...",
      options: [
        { label: "A", text: "Texto da alternativa A" },
        { label: "B", text: "Texto da alternativa B" },
        { label: "C", text: "Texto da alternativa C" },
        { label: "D", text: "Texto da alternativa D" },
        { label: "E", text: "Texto da alternativa E" }
      ],
      correctLabel: "B",
      explanation: "Resolução comentada detalhada extraída do material de estudo..."
    }
  ]
};
```

#### 🔹 Para Banca CEBRASPE (Certo / Errado):
```javascript
CEBRASPE: [
  {

    ],

  }
]
```

## 🤖 3. Como os Tópicos do PDF Alimentam o Motor de IA

Quando o usuário seleciona um ou mais assuntos no painel da aplicação, os `label` dos tópicos extraídos do edital são concatenados e passados no prompt enviado para os modelos **Gemma 4 31B** ou **DeepSeek V4 Flash**:

```javascript
const topicObjList = TOPICS_CATALOG.filter(t => topics.includes(t.id));
const topicLabels = topicObjList.map(t => t.label).join("; ");

const prompt = `Você é um especialista e examinador sênior da banca ${banca}.
Assuntos Selecionados do Edital: [${topicLabels}].
Elabore questões inéditas focadas estritamente nestes tópicos.`;
```

## 🐍 4. Script Python para Automatizar Extração de PDFs

Se você possui um arquivo PDF longo com o edital ou apostilas, use este script Python para extrair o texto limpo automaticamente:

```python
import pypdf

def extract_text_from_pdf(pdf_path):
    reader = pypdf.PdfReader(pdf_path)
    text = ""
    for page in reader.pages:
        text += page.extract_text() + "\n"
    return text
```
